# Triakis – Ichorborn Species Pack
A Foundry VTT module providing the **Ichorborn**, a fully‑featured species for the world of **Triakis**, including all subspecies, traits, and racial feats.  
Built for the **D&D 5e 5.2.5 Species System** and compatible with **Foundry VTT v13**, **Midi‑QOL**, and **Dynamic Active Effects (DAE)**.

This module is part of the larger Triakis campaign setting and is designed for both table‑ready play and worldbuilding expansion.

---

## ✨ Features

### ✔ Fully Implemented Species
- **Ichorborn** (parent species)
- **SandWrought** (subspecies)
- **RuinTouched** (subspecies)
- **ChoirlessMarked** (subspecies)

### ✔ Hybrid Automation
Core mechanical features use Foundry’s Active Effects system:
- Movement modes  
- Senses  
- Resistances  
- Skill proficiencies  
- Natural armor  

No macros required.

### ✔ Complete Trait & Feat Library
Includes all racial traits and racial feats:
- **Ichor Adaptation**
- **Sundered Resilience**
- **Ichor Sense**
- **Sandwrought Carapace**
- **Sandwrought Burrow**
- **Ruin Echo**
- **Ruin Sight**
- **Choirless Stillness**
- **Choirless Null Field**
- **Ichorstoked Vitality**
- **Ruinforged Adaptation**
- **Avatar’s Echo**

All items are included in a single compendium for easy drag‑and‑drop use.

2. Go to **Add‑on Modules → Install Module**
3. Paste the manifest URL from this repository’s `module.json`
4. Install and enable the module in your world
